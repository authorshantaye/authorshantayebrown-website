# authorshantayebrown.com

Next.js (App Router) + Tailwind CSS site for author Shantaye Brown. Hosted on Vercel; every push to `main` redeploys.

## Edit content
- **Links, email, YouTube videos:** `lib/site.js`
- **Author photo:** `public/images/shantaye.jpg`
- **Book text / cover:** `components/Books.js`

## Run locally
```bash
npm install
npm run dev   # http://localhost:3000
```
